Avisador Teams

Dos rutas automáticas resuelven el mismo problema: leer Microsoft Teams sin permiso de administrador. Una corre una vez al día y te avisa; la otra espera tus preguntas y contesta al instante. Comparten un solo archivo como memoria.

Qué hace cada pieza

GitHub Actions Cron gratis en la nube. Dispara el workflow diario a las 7:00 AM hora Ciudad Madero — no depende de que tu laptop o celular estén prendidos. Playwright Automatización de navegador. Abre un Chromium invisible con tu sesión de Teams ya capturada (copiando tu perfil de Brave — Microsoft bloquea el login automatizado directo). Teams teams.cloud.microsoft. Se lee el feed de Actividad y, tarea por tarea, si está "Entregada" o "No entregada" y sus instrucciones. latest_activity.json La memoria compartida. Un archivo en el repo (público) donde la Línea 1 escribe cada mañana y de donde la Línea 2 lee cada vez que le preguntas algo. Telegram · sendMessage API de Telegram, modo envío. Así te llega el resumen diario a tu chat con el bot. Telegram · Webhook API de Telegram, modo aviso instantáneo. En vez de que el bot pregunte cada rato "¿hay mensajes?", Telegram le avisa apenas escribes. Cloudflare Worker Función en la nube, siempre lista. Recibe el aviso de Telegram, arma tu pregunta junto con el contexto guardado y llama a la IA — sin servidor propio que mantener prendido. Gemini API generateContent · gemini-2.5-flash. Recibe tu pregunta + el contexto de tareas y redacta la respuesta en español, sin markdown, filtrando lo ya entregado.

Por qué no fue más directo

No leer Teams por su API oficial fue decisión forzada, no de diseño — se probaron tres caminos antes de este:

descartado Microsoft Graph API Los permisos de tareas y mensajes de canal requieren aprobación de un administrador — la escuela no puede dárselos a un alumno individual.
descartado Login automatizado Microsoft detecta que Playwright controla el navegador (sin importar cuál) y bloquea el inicio de sesión interactivo antes de completarlo.
descartado Oracle Cloud (VPS gratis) Sin capacidad disponible para instancias gratuitas en la región de Querétaro — reintentado varias veces, sin éxito.
